# Exercise solutions

This folder contains solution files for the exercises noted in each of the chapters.
Specifically, there is one file per chapter, named `<chapter_slug>_solutions.ipynb`, 
where the slug is the chapter notebook's file name (for example `reviewing_supervised_linear_models_solutions.ipynb`).
Each notebook is embedded into `appendices/exercise_solutions.qmd`, which is always published with the book.

We use the following conventions:
- One `## Exercise N` section per exercise, in the chapter's numbering.
- Where possible we try to reuse the chapter's own code and data as much as possible with minimal new added code just for the exerises.
- Notebooks are executed locally before committing (the site build does not run Python), and they contain no assertions or verification scaffolding.
